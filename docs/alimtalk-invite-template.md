# 카카오 알림톡 템플릿 (가입 안내)

Student Card 에서 들어왔지만 아직 유스피킹 아이디를 만들지 않은 학생에게 보내는
가입 안내입니다. 월말 리포트 템플릿과 **문구가 달라 따로 심사**를 받아야 합니다.

---

## 1. 템플릿 문안 (이대로 등록)

**템플릿명**: 스피킹 과제 계정 등록 안내
**메시지 유형**: 기본형
**강조 유형**: 선택 안 함
**카테고리**: 서비스 이용 > 이용 안내/공지 (가장 가까운 항목)

```
[목동유쌤영어] 스피킹 과제 계정 등록 안내

안녕하세요, 목동유쌤영어입니다.
#{이름} 학생이 수강 중인 반의 스피킹 과제 제출 방법을 안내드립니다.

■ 수강반: #{반}
■ 과제 제출: 유스피킹(온라인 녹음 과제)

수강반의 스피킹 과제는 유스피킹에서 녹음해 제출합니다.
과제 제출을 위해 아래 [계정 등록하기] 버튼을 눌러 학생 아이디와 비밀번호를 등록해 주세요.

※ 본 메시지는 목동유쌤영어 수강생의 수업 운영 안내를 위해 발송되었습니다.
```

> **왜 이렇게 썼나 — 심사 기준**
> 알림톡은 정보성 메시지만 보낼 수 있고, 아직 가입하지 않은 사람에게 '가입' 을 권하는
> 문구는 광고(가입 유도)로 보고 반려되기 쉽다. 이 메시지의 근거는 **수강 계약** — 받는 분은
> 이미 학원에 등록한 수강생의 학부모이고, 유스피킹은 그 반의 과제를 내는 도구다. 그래서
> '가입' 대신 '과제 제출용 계정 등록' 으로 쓰고, 받는 이유와 수신 근거를 문구에 넣었다.
>
> 문구는 전환·일원화 두 상태에 모두 맞게 썼다 (심사 후에는 바꿀 수 없다).
> - 전환 중: 버튼이 담임 선생님의 가입 신청 화면을 연다 → 신청 후 선생님 승인
> - 일원화 후: 버튼이 학생 개인 등록 화면을 연다 → 아이디만 정하면 바로 사용
>
> 심사 메모 칸이 있으면: "학원 수강생(재원생) 학부모에게, 수강 중인 반의 과제 제출 도구
> 계정 등록 방법을 안내하는 수업 운영 메시지입니다. 재원 명단에 있는 학생에게만 발송합니다."

### 버튼 (1개)

| 항목 | 값 |
|---|---|
| 버튼명 | 계정 등록하기 |
| 버튼 유형 | 웹링크 (WL) |
| 모바일 링크 (필수) | `https://#{링크}` |
| PC 링크 (선택) | `https://#{링크}` |
| 외부 브라우저로 링크 열기 | 꺼 둠 |

> ⚠️ 월말 리포트와 같은 규칙입니다. `#{링크}` 만 넣으면 등록이 막히니
> `https://` 를 앞에 직접 적어 주세요. 프로그램은 `https://` 를 뺀 값을 보냅니다.

---

## 2. 변수

| 변수 | 예시 | 설명 |
|---|---|---|
| `#{이름}` | 강주원 | 학생 이름 (Student Card 기준) |
| `#{반}` | M3B TTH | 유스피킹 반 이름 |
| `#{링크}` | `yuspeaking.yussam.com/student/join/3fa…` | 개인 가입 링크에서 `https://` 를 뺀 부분 |

일원화 전(전환 중)에는 아직 유스피킹에 학생이 없어서, 개인 링크 대신 **담임 선생님의
가입 신청 링크**(`…/student/signup?t=…`)가 들어갑니다. 같은 템플릿으로 나갑니다.

---

## 3. 환경변수

Vercel → Settings → Environment Variables 에 추가하고 재배포합니다.

```
SOLAPI_INVITE_TEMPLATE_ID = 승인받은 가입 안내 템플릿 ID
```

API 키·시크릿·발신프로필·발신번호는 월말 리포트와 같이 씁니다. 등록 상태는
**운영자 → 설정** 화면에서 확인할 수 있습니다.

---

## 4. 보내는 곳

**선생님 → 🧾 명단 확인 → 가입하지 않은 학생** 에서 체크하고 보냅니다.

- 학부모 번호로 보내고, 없으면 학생 번호로 보냅니다.
- 보낸 날짜와 횟수가 학생 옆에 표시됩니다. 이미 보낸 학생은 체크가 기본으로 꺼져 있어요.
- 알림톡을 쓰기 전이라도 학생마다 **링크 복사** 버튼이 있어 문자·카톡으로 직접 보낼 수 있습니다.
- 링크는 한 번 가입하면 더 쓸 수 없습니다. 잘못 보냈더라도 다른 사람이 그 학생 이름으로
  이미 가입했다면 바로 알 수 있어요 (학생은 '이미 가입을 마친 링크' 화면을 보게 됩니다).
