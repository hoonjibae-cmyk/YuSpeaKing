# 유스피킹 출제 방식과 내부 폰트 (2026-11-28)

- 전체 지문 입력/PDF/사진 추출 뒤 `원문 그대로 추출` 또는 `요약문 만들기`를 선택한다. 요청 문장 수는 10~15개, 기본 10개다.
- 원문 추출은 AI가 문장 번호만 고르고 서버가 원문 문자열을 가져온다. 원문 순서·철자·문장 부호·내부 공백을 유지한다. PDF 줄바꿈, 호칭 약어와 소수점 문장 경계를 처리한다. 부족한 문장 수는 생성 전 안내한다.
- 요약문은 전체 글의 핵심 내용을 새 영어 문장으로 쓴다. 각 문장의 원문 근거 번호, 정확한 개수, 중복 및 문장 단위를 검사한다. 의미의 완전한 일치까지 기계적으로 보장하는 검사는 아니며 교사가 생성 결과를 확인할 수 있다.
- 잘못된 AI 응답은 한 번만 재시도한다. 실패한 결과를 자르거나 원문 전체로 대체하지 않는다. 원문·모드·개수 변경 시 기존 결과를 비운다. 처리 중 입력을 잠그고, 추출 문장은 읽기 전용으로 유지한다. 수동 문장 제거·복구는 가능하다.
- 기존 설정의 Anthropic 모델과 사용량 집계를 유지한다. 문장 생성 API는 승인된 교사/관리자만 허용한다. 과제 저장, 샘플 음성, 반 권한 검사는 기존 경로를 유지한다.
- 본문 14px, 섹션 제목 17px(좁은 화면 16px), 설명·라벨 13px, 버튼 14px, 입력 16px/400 굵기, 조작 높이 최소44px로 맞췄다. 하루리뷰와 같은 Pretendard를 쓴다.

## 검증

- 생성/추출/실패 재시도/권한 검사 7개와 기존 반 출제 권한 3개 테스트 통과.
- TypeScript 및 Next.js 운영 빌드 통과. 기존 다른 셸의 img 최적화 경고 2개만 남음.
- 실제 폼 컴포넌트와 가상 데이터로 Edge 2552/1366 및 430/390/360/320px 폭에서 폰트 크기·가로 넘침 확인. 모바일은 데스크톱 크기 재현이다.
- 운영 확인 결과는 매일러닝 저장소의 docs/assignment-authoring-modes.md에 보존한다.
