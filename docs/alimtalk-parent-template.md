# 카카오 알림톡 템플릿 (학부모 링크 안내)

학부모께 자녀의 스피킹 과제 기록을 볼 수 있는 **학부모 열람 링크**(`/parent/토큰`)를
보내는 안내입니다. 월말 리포트·가입 안내와 **문구가 달라 따로 심사**를 받아야 합니다.

---

## 1. 템플릿 문안 (이대로 등록)

**템플릿명**: 스피킹 과제 학습 현황 안내
**메시지 유형**: 기본형
**강조 유형**: 선택 안 함
**카테고리**: 서비스 이용 > 이용 안내/공지 (가장 가까운 항목)

```
[목동유쌤영어] 스피킹 과제 학습 현황 안내

안녕하세요, 목동유쌤영어입니다.
#{이름} 학생의 스피킹 과제 학습 현황을 확인하실 수 있는 페이지를 안내드립니다.

■ 수강반: #{반}
■ 확인 내용: 과제 제출 현황, 녹음 평가 결과, 선생님 피드백

아래 [학습 현황 보기] 버튼을 누르시면 별도 가입이나 로그인 없이 바로 확인하실 수 있습니다.
본 링크는 #{이름} 학생 학부모님 전용이니 다른 분과 공유하지 말아 주세요.

※ 본 메시지는 목동유쌤영어 수강생 학부모님께 수업 운영 안내를 위해 발송되었습니다.
```

> **왜 이렇게 썼나 — 심사 기준**
> 알림톡은 정보성 메시지만 보낼 수 있다. 이 메시지의 근거는 **수강 계약**: 받는 분은
> 이미 학원에 등록한 수강생의 학부모이고, 링크는 그 자녀의 과제 기록을 보여 준다.
> 그래서 '가입'·'이용해 보세요' 같은 권유 문구 없이, 무엇을 볼 수 있는지와 수신 근거를
> 문구에 넣었다. 링크가 개인 전용이라는 점도 적어, 공유해서 생기는 문제를 막는다.
>
> 심사 메모 칸이 있으면: "학원 수강생(재원생)의 학부모님께, 자녀의 과제 제출·평가 현황을
> 확인할 수 있는 개인 페이지 주소를 안내하는 수업 운영 메시지입니다. 재원생 학부모 번호로만 발송합니다."

### 버튼 (1개)

| 항목 | 값 |
|---|---|
| 버튼명 | 학습 현황 보기 |
| 버튼 유형 | 웹링크 (WL) |
| 모바일 링크 (필수) | `https://#{링크}` |
| PC 링크 (선택) | `https://#{링크}` |
| 외부 브라우저로 링크 열기 | 꺼 둠 |

> ⚠️ 월말 리포트와 같은 규칙입니다. `#{링크}` 만 넣으면 등록이 막히니
> `https://` 를 앞에 직접 적어 주세요. 프로그램은 `https://` 를 뺀 값을 보냅니다.

---

## 2. 변수

| 변수 | 예시 | 설명 |
|---|---|---|
| `#{이름}` | 강주원 | 학생 이름 |
| `#{반}` | M3B TTH | 유스피킹 반 이름 |
| `#{링크}` | `yuspeaking.yussam.com/parent/3fa…` | 학부모 열람 링크에서 `https://` 를 뺀 부분 |

---

## 3. 환경변수

Vercel → Settings → Environment Variables 에 추가하고 재배포합니다.

```
SOLAPI_PARENT_TEMPLATE_ID = 승인받은 학부모 링크 템플릿 ID
```

API 키·시크릿·발신프로필·발신번호는 월말 리포트와 같이 씁니다. 등록 상태는
**운영자 → 설정** 화면에서 확인할 수 있습니다.

---

## 4. 보내는 곳

**선생님 → 반 → 학생 명단 → 📩 학부모 링크 보내기** 에서 체크하고 보냅니다.

- **학부모 번호로만** 보냅니다. 학부모 번호가 없는 학생은 보내지 않습니다 (학생 번호로
  대신 보내지 않습니다). 반 화면의 학생 옆 **📱 연락처**에 먼저 적어 주세요.
- 링크가 아직 없는 학생은 보낼 때 자동으로 만들어집니다. 이미 있는 링크는 그대로 씁니다.
- 보낸 날짜와 횟수가 학생 옆에 표시됩니다. 이미 보낸 학생은 체크가 기본으로 꺼져 있어요.
- 반 화면에서 링크를 **재발급**하면 전에 보낸 링크는 더 열리지 않습니다. 재발급했다면
  여기서 다시 보내 주세요.
- 담임·공동 관리 선생님만 보낼 수 있습니다 (보조강사는 보기 전용).
