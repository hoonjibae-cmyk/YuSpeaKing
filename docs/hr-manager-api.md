# HR manager 연동 규격 요청서

유스피킹이 HR manager 에서 **반 목록**과 **반별 학생 명단(+연락처)** 을 읽어
가려고 합니다. 쓰기는 하지 않고, 읽기만 합니다.

아래 두 가지만 열어 주시면 됩니다. 응답 필드 이름은 아래와 달라도 괜찮습니다 —
실제 이름만 알려 주시면 유스피킹 쪽에서 맞춥니다
(`src/lib/hr/client.ts` 한 파일만 고치면 됩니다).

## 1. 인증

현재 구현은 헤더 방식입니다.

```
Authorization: Bearer <HR_API_KEY>
Accept: application/json
```

다른 방식(예: `X-API-KEY`, 쿼리스트링 토큰)이라면 알려 주세요.

## 2. 반 목록

```
GET {HR_API_BASE}/classes
```

```json
[
  { "id": "1024", "name": "화목 B반", "teacherEmail": "rachel@example.com" }
]
```

| 필요한 값 | 쓰는 곳 |
| --- | --- |
| 반 식별자 (불변) | 유스피킹 반과 이어 두는 열쇠. 반 이름이 바뀌어도 연결이 유지되도록 **이름이 아닌 ID** 가 필요합니다. |
| 반 이름 | 운영자가 매칭 화면에서 눈으로 찾을 때. 이름이 같으면 자동으로 골라 둡니다. |
| 담당 선생님 (선택) | 매칭 화면에서 같은 이름의 반을 구분할 때. 없어도 동작합니다. |

## 3. 반별 학생 명단

```
GET {HR_API_BASE}/classes/{반ID}/students
```

```json
[
  {
    "id": "88213",
    "name": "홍길동A",
    "studentPhone": "010-1234-5678",
    "parentPhone": "010-8765-4321"
  }
]
```

| 필요한 값 | 쓰는 곳 |
| --- | --- |
| 학생 식별자 (불변) | 이름이 바뀌어도 연결이 끊기지 않게 하는 열쇠. |
| 이름 | 유스피킹 명단과 맞춰 봅니다. 뒤에 붙은 A·B 구분자는 유스피킹이 알아서 처리합니다. |
| 학생 휴대폰 | 보관용. |
| 학부모 휴대폰 | **월말 리포트 알림톡 발송에 씁니다.** |

> 재원생만 내려주시면 됩니다. 퇴원생이 섞여 내려오면 선생님 화면에 "등록되지
> 않은 학생" 으로 잘못 뜹니다.

## 4. 유스피킹이 지키는 것

- **선생님이 유스피킹에 만든 반, 그리고 운영자가 직접 이어 준 반만** 조회합니다.
  이어지지 않은 반은 호출조차 하지 않습니다.
- 호출 시점은 ① 매일 새벽 4시 자동 1회, ② 운영자가 매칭 화면에서 버튼을 누를 때,
  ③ 선생님이 명단 확인 화면에서 버튼을 누를 때. 화면을 열 때마다 부르지 않습니다.
- 받은 값 중 저장하는 것은 학생 ID·학생 휴대폰·학부모 휴대폰뿐입니다.

## 5. 유스피킹 쪽 환경변수

Vercel 환경변수로만 넣습니다 (앱 화면에서 입력하지 않습니다).

```
HR_API_BASE=https://hr.example.com/api
HR_API_KEY=...
```
