# 카카오 알림톡 템플릿 (월말 리포트)

유스피킹이 학부모께 월말 리포트를 보낼 때 쓰는 알림톡 템플릿입니다.
알림톡은 **카카오 심사를 통과한 템플릿으로만** 보낼 수 있으므로, 아래 문안을
솔라피 콘솔에 그대로 등록하고 승인을 받아야 합니다.

---

## 1. 등록 전 준비

| 항목 | 설명 |
|---|---|
| 카카오 비즈니스 채널 | 학원 공식 채널. 솔라피에 연동하면 **발신프로필 ID(pfId)** 가 나옵니다 |
| 발신번호 | 알림톡이 막혔을 때 문자로 대체 발송하는 데 씁니다. 사전 등록 필요 |

> 채널 개설 → 솔라피 연동 → 템플릿 등록 → 심사(영업일 1~2일) 순서입니다.
> 심사는 **광고성 문구가 없어야** 통과합니다. 아래 문안은 정보성으로 작성했습니다.

---

## 2. 템플릿 문안 (이대로 등록)

**템플릿명**: 월말 리포트 안내
**메시지 유형**: 기본형
**강조 유형**: 선택 안 함

```
[목동유쌤영어] 월말 리포트 안내

안녕하세요. 목동유쌤영어입니다.

#{이름} 학생의 #{월} 영어 스피킹 월말 리포트가 준비되었습니다.

한 달 동안의 과제 제출 기록과 발음 평가, 담당 선생님의 코멘트를 확인하실 수 있습니다.

아래 버튼을 눌러 확인해 주세요.
```

### 버튼 (1개)

| 항목 | 값 |
|---|---|
| 버튼명 | 리포트 확인하기 |
| 버튼 유형 | 웹링크 (WL) |
| 모바일 링크 (필수) | `https://#{링크}` |
| PC 링크 (선택) | `https://#{링크}` |
| 외부 브라우저로 링크 열기 | 꺼 둠 (카카오톡 안에서 열림) |

> ⚠️ **`#{링크}` 만 넣으면 [버튼 만들기] 가 눌리지 않습니다.**
> 카카오는 버튼 주소의 프로토콜을 템플릿에 **고정으로** 적게 합니다.
> 그래서 `https://` 는 템플릿에 직접 쓰고, 변수에는 그 뒤부터 넣습니다.
> 프로그램도 이에 맞춰 `#{링크}` 에 `https://` 를 뺀 값을 보냅니다.

---

## 3. 변수

프로그램이 발송할 때 아래 값을 채워 보냅니다. **변수명을 바꾸면 발송이
실패하므로** 템플릿에 그대로 적어 주세요.

| 변수 | 예시 | 설명 |
|---|---|---|
| `#{이름}` | 강주원 | 학생 이름 |
| `#{월}` | 2026년 9월 | 리포트 대상 월 |
| `#{링크}` | `yuspeaking.yussam.com/report/a1b2c3…` | 리포트 주소에서 **`https://` 를 뺀 부분**. 버튼이 `https://` + 이 값으로 열립니다 |

---

## 4. 승인 후 환경변수 등록

Vercel → 프로젝트 → Settings → Environment Variables 에 넣고 재배포합니다.

```
SOLAPI_API_KEY       = 솔라피 API 키
SOLAPI_API_SECRET    = 솔라피 API 시크릿
SOLAPI_PFID          = 발신프로필 ID (카카오 채널 연동 후 발급)
SOLAPI_TEMPLATE_ID   = 승인받은 템플릿 ID
SOLAPI_SENDER        = 등록된 발신번호 (예: 0212345678)
```

리포트 주소를 만드는 데 쓰이므로 `NEXT_PUBLIC_APP_URL` 도 정식 도메인으로
들어 있어야 합니다. 비어 있으면 발송 버튼이 오류를 띄우고 멈춥니다 —
학부모에게 깨진 링크가 가는 것보다 낫기 때문입니다.

등록 상태는 **운영자 → 설정** 화면에서 확인할 수 있습니다.
`SOLAPI_SENDER` 가 비어 있으면 문자 대체 발송이 꺼지고, 알림톡이 막힌
학부모에게는 아무것도 가지 않습니다.

---

## 5. 심사에서 반려되는 흔한 이유

- 광고·홍보 문구 (수강 권유, 할인 안내 등) → 지금 문안에는 없습니다
- 변수만으로 이루어진 문장 → 고정 문구를 충분히 두었습니다
- 채널 추가 유도 문구 → 넣지 마세요
- 링크가 변수인데 설명이 없는 경우 → 버튼명 "리포트 확인하기"로 명시했습니다
- 버튼 주소를 `#{링크}` 처럼 프로토콜 없이 변수로만 둔 경우 → 등록 단계에서
  막힙니다. `https://#{링크}` 로 적으세요

---

## 6. 발송 흐름 (선생님 화면)

```
반 화면 → 📄 월말 리포트
  ① 초안 일괄 생성   (없는 학생만 / 전체 다시)
  ② 이름을 눌러 검토·수정 → 링크 발급
  ③ 보낼 학생 체크 → 알림톡 보내기
```

- 연락처는 **반 화면의 학생 명단**에서 입력합니다.
- 리포트를 고쳐 저장하면 **같은 링크에 바로 반영**되므로 다시 보낼 필요가 없습니다.
- 이미 보낸 학생은 목록에 발송일이 표시되고 체크가 기본 해제됩니다.
